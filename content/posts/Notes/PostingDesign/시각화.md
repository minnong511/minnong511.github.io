# 탑다운 시각화 (작동과정 볼 때, API 명세 같은 거)

아래 주제를 **작동 과정을 눈으로 따라가는 단계별 애니메이션**으로 시각화해줘.

주제: [설명할 개념]
예시 입력: [실제로 흘려보낼 데이터나 요청]
진행 단계: [시작 → 단계 1 → 단계 2 → 결과]

핵심 원칙은 “글을 읽어서 이해하는 것이 아니라, 작동하는 모습을 보고 이해한다”야.

**화면 구성**
- 위에서 아래로 이어지는 세로 흐름으로 배치해줘.
- 처음에는 단계 이름과 ‘시작’ 버튼만 보여줘.
- 작은 데이터 칩이 경로를 따라 이동하고, 현재 단계만 강조해줘.
- 현재 단계 바로 오른쪽, 같은 높이에 처리 과정과 결과를 표시해줘. 모바일에서는 해당 단계 바로 아래에 표시해줘.
- 설명 문단, 정보 표, 상세 값 목록을 처음부터 펼치지 마.

**단계별 연출**
- 각 단계는 ‘도착 → 처리 또는 판단 → 결과 출력’ 순서로 진행해줘.
- 실제 예시 값을 사용해서 무엇이 비교·선택·변경되는지 보여줘.
- 비교는 값이 나란히 나타나 일치 표시가 붙는 모습으로, 선택은 후보 중 하나가 강조되는 모습으로, 변환은 데이터 칩의 내용이 바뀌는 모습으로 표현해줘.
- 데이터가 유지되는 단계에서는 값을 억지로 변경하지 마.
- 다음 단계로 넘어가면 이전 상세 정보는 접고, 작은 완료 표시와 결과만 남겨줘.
- 아직 도달하지 않은 단계의 결과는 미리 보여주지 마.

**텍스트 제한**
- 단계 이름을 제외하고, 한 번에 짧은 값과 상태 문구 2~3개만 보여줘.
- “조건 일치”, “대상 선택”, “변환 완료”처럼 짧게 써줘.
- 이동, 색 변화, 선택 효과로 전달할 수 있는 내용은 문장으로 반복하지 마.
- 용어 정의와 기술적 보충 설명은 정보 아이콘을 눌렀을 때만 보여줘.

**조작**
- ‘시작’ 버튼을 누르면 데이터 칩을 생성하고, 첫 단계부터 바로 자동 재생해줘.
- 시작 후 ‘이전’, ‘다음’, ‘일시 정지’, ‘초기화’를 제공하고, 정지하면 ‘일시 정지’를 ‘재생’으로 바꿔줘.
- ‘이전’이나 ‘다음’을 누르면 자동 재생을 멈추고 수동 진행으로 전환해줘. ‘재생’을 누르면 현재 위치부터 이어서 진행해줘.
- 수동 진행에서는 ‘다음’을 누를 때마다 도착, 판단, 결과를 한 박자씩 공개해줘.
- 자동 재생도 같은 순서를 따르고, 각 변화 사이에 알아볼 수 있는 짧은 정지를 넣어줘.
- 이전 단계로 돌아가면 당시 상태를 다시 보여줘.
- 마지막 결과까지 보여주면 자동 재생을 멈추고 완료 표시를 남겨줘. ‘초기화’를 누르면 시작 전 화면으로 돌아가게 해줘.

**디자인**
- 흰 배경, 진한 글자, 파란 강조색을 기본으로 사용해줘.
- 현재 단계는 파란색, 완료 단계는 체크 표시, 대기 단계는 옅은 회색으로 구분해줘.
- 굵은 박스와 장식을 줄이고, 여백과 정렬로 구조를 표현해줘.
- 애니메이션 중 요소가 겹치거나 화면 배치가 크게 흔들리지 않게 해줘.
- 보조 정보는 관련 단계에서만 잠깐 펼치고, 실제 흐름과 구분해 연결해줘.

완성 기준은 **“설명 문단을 읽지 않아도, 어떤 입력이 들어와 각 단계에서 어떻게 처리되고 어떤 결과가 나오는지 따라갈 수 있는가”**야. 실제 동작 순서와 개념의 정확성을 유지하면서 시각적으로 단순하게 만들어줘.
