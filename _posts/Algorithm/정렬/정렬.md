# 정렬

실무나 코딩테스트에서는 sorted(), sort()를 사용하지만, 정렬 원리를 공부해야 할 필요가 있다면, 버블 정렬, 선택 정렬, 삽입 정렬, 병합 정렬, 퀵 정렬 등을 직접 구현하는 것이 좋다

# 일단 자주 쓰는 sort(), sorted()

### 일단 자주 쓰는 `sort()`, `sorted()`

파이썬에서는 리스트를 정렬할 때 주로 `sort()`와 `sorted()`를 사용한다.

#### `list.sort()`

```python
numbers = [5, 2, 6, 3]

numbers.sort()

print(numbers)
# [2, 3, 5, 6]
```

`.sort()`는 **기존 리스트 자체를 정렬한다.**

따라서 원본 리스트의 순서가 변경된다.

```text
변경 전: [5, 2, 6, 3]
변경 후: [2, 3, 5, 6]
```

또한 `.sort()`는 정렬된 리스트를 반환하지 않고 `None`을 반환한다.

```python
numbers = [5, 2, 6, 3]

result = numbers.sort()

print(numbers)
# [2, 3, 5, 6]

print(result)
# None
```

따라서 다음과 같이 작성하면 안 된다.

```python
numbers = numbers.sort()

print(numbers)
# None
```

---

#### `sorted()`

```python
numbers = [5, 2, 6, 3]

result = sorted(numbers)

print(numbers)
# [5, 2, 6, 3]

print(result)
# [2, 3, 5, 6]
```

`sorted()`는 **원본을 유지하고 정렬된 새로운 리스트를 반환한다.**

```text
원본 리스트:   [5, 2, 6, 3]
새로운 리스트: [2, 3, 5, 6]
```

`sorted()`는 리스트뿐만 아니라 문자열, 튜플 등의 반복 가능한 객체에도 사용할 수 있다. 다만 정렬 결과는 항상 리스트로 반환된다.

```python
text = "python"

result = sorted(text)

print(result)
# ['h', 'n', 'o', 'p', 't', 'y']
```

---

#### 내림차순 정렬

`sort()`와 `sorted()` 모두 `reverse=True`를 사용하면 내림차순으로 정렬할 수 있다.

```python
numbers = [5, 2, 6, 3]

numbers.sort(reverse=True)

print(numbers)
# [6, 5, 3, 2]
```

```python
numbers = [5, 2, 6, 3]

result = sorted(numbers, reverse=True)

print(result)
# [6, 5, 3, 2]
```

---

#### 원하는 기준으로 정렬하기

`key`를 사용하면 각 값을 어떤 기준으로 정렬할지 지정할 수 있다.

```python
words = ["banana", "kiwi", "apple"]

result = sorted(words, key=len)

print(result)
# ['kiwi', 'apple', 'banana']
```

문자열 자체가 아니라 문자열의 길이인 `len`을 기준으로 정렬한다.

```text
kiwi   → 길이 4
apple  → 길이 5
banana → 길이 6
```

---

#### `sort()`와 `sorted()` 비교

| 구분 | `list.sort()` | `sorted()` |
|---|---|---|
| 원본 변경 | 변경함 | 변경하지 않음 |
| 반환값 | `None` | 정렬된 새 리스트 |
| 사용 대상 | 리스트만 가능 | 리스트, 튜플, 문자열 등 |
| 내림차순 | `reverse=True` | `reverse=True` |
| 정렬 기준 | `key` | `key` |

원본을 바꿔도 된다면 다음처럼 사용한다.

```python
numbers.sort()
```

원본을 유지해야 한다면 다음처럼 사용한다.

```python
sorted_numbers = sorted(numbers)
```

둘 다 내부적으로는 파이썬의 정렬 알고리즘인 **Timsort**를 사용한다. Timsort는 삽입 정렬과 병합 정렬의 장점을 활용한 알고리즘이며, 이미 정렬되어 있거나 일부가 정렬된 데이터에서도 효율적으로 동작한다.

일반적인 시간 복잡도는 다음과 같다.

```text
평균: O(n log n)
최악: O(n log n)
이미 정렬된 데이터: O(n)
```

**핵심은 `sort()`는 원본을 변경하고 `None`을 반환하며, `sorted()`는 원본을 유지하고 새로운 리스트를 반환한다는 것이다.**

# 1. 버블 정렬 

옆에 있는 두 값을 비교하면서 큰 값을 오른쪽 이동시키는 방식 

def bubble_sort(numbers):
    numbers = numbers.copy()
    n = len(numbers)

    for i in range(n-1):
        for j in range(n-1-i):
            if numbers[j] > numbers[j+1]:
                number[j], numbers[j+1] = numbers[j+1], 

numbers[j]

    return numbers 

numbers = [5, 2, 6, 3]
print(bubble_sort(numbers))

결과 

[2,3,5,6]

첫 번째 반복에서는 다음과 같이 진행 

[5, 2, 6, 3]
 ↑  ↑
5 > 2이므로 교환


[2, 5, 6, 3]
    ↑  ↑
5 < 6이므로 유지


[2, 5, 6, 3]
       ↑  ↑
6 > 3이므로 교환

한 바퀴가 끝나면 가장 큰 값 6이 오른쪽 끝에 위치

시간 복잡도: O(n²)
