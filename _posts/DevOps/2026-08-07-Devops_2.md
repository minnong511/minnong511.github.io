# CD - Continuous Delivery / Deployment 

git push
   ↓
CI
   ↓
Ruff
pytest
build
   ↓
CD
   ↓
Server Deployment

즉, 테스트가 성공하면 자동으로 배포한다. 

main branch push
       ↓
GitHub Actions
       ↓
pytest PASS
       ↓
Docker Image Build
       ↓
Server Deploy

사람이 서버에 접속해서 

git pull
pyhthon app.py 

할 필요가 줄어든다.
