# Vue 프로젝트 디렉터리 구조

| 파일 또는 폴더 | 설명 |
|---|---|
| `index.html` | 애플리케이션의 진입점입니다. 브라우저가 처음 읽는 HTML 파일이며, Vue 앱이 들어갈 `<div id="app">`를 포함합니다. |
| `package.json` | 프로젝트 이름, 버전, 실행 스크립트, 설치된 의존성 라이브러리를 기록합니다. |
| `vite.config.js` | Vite 개발 서버와 빌드 엔진의 설정 파일입니다. |
| `.gitignore` | Git에 저장하지 않을 파일과 폴더를 지정합니다. 예: `node_modules`, `dist` |
| `public/` | 브라우저에 그대로 제공되는 정적 파일 폴더입니다. Vite가 파일을 컴파일하거나 최적화하지 않습니다. |
| `src/` | Vue 애플리케이션의 실제 소스 코드가 들어 있는 폴더입니다. |
| `src/main.js` | Vue 애플리케이션을 시작하는 진입 JavaScript 파일입니다. `index.html`에서 호출됩니다. |
| `src/App.vue` | 애플리케이션의 최상위 루트 컴포넌트입니다. 다른 화면이 표시될 기본 영역을 제공합니다. |
| `src/style.css` | 애플리케이션 전체에 적용되는 CSS 파일입니다. 프로젝트 설정에 따라 `src/assets/main.css`로 존재할 수도 있습니다. |
| `src/assets/` | CSS, 이미지, 로고, 폰트 등 Vite가 컴파일하고 최적화할 소스 자원을 보관합니다. |
| `src/components/` | 여러 화면에서 재사용할 작은 Vue 컴포넌트를 보관합니다. |
| `HelloWorld.vue` | Vue 프로젝트 생성 시 제공되는 예시 컴포넌트입니다. 보통 `App.vue`에서 호출됩니다. |
| `src/router/` | SPA의 페이지 이동 경로를 정의합니다. URL에 따라 어떤 화면을 보여줄지 결정합니다. |
| `src/stores/` | Pinia를 이용한 전역 상태 저장소를 보관합니다. 여러 컴포넌트가 함께 사용할 데이터를 관리합니다. |
| `src/views/` | 여러 컴포넌트를 조립해 만든 완성된 페이지 단위 화면을 보관합니다. 예: `HomeView.vue`, `AboutView.vue` |

## Vue 애플리케이션 작동 구조

```text
브라우저가 http://localhost:5173 접속
                ↓
          index.html 로드
                ↓
       <div id="app"> 확인
                ↓
          src/main.js 실행
                ↓
      createApp(App)으로 Vue 시작
                ↓
          src/App.vue 표시
                ↓
      <RouterView />가 현재 URL 확인
                ↓
    router/index.js에서 경로와 화면 연결
                ↓
      해당 views 화면을 브라우저에 표시
```

## 파일 간 호출 관계

```text
index.html
   └── src/main.js
          └── App.vue
                 └── RouterView
                        └── router/index.js
                               └── views/AboutView.vue
                                      └── components 재사용
```

## 예시: `/about` 페이지가 표시되는 과정

1. 사용자가 `http://localhost:5173/about`에 접속합니다.
2. 브라우저가 `index.html`을 읽습니다.
3. `index.html`이 `src/main.js`를 실행합니다.
4. `main.js`가 Vue 앱과 Router를 등록합니다.
5. `App.vue`의 `<RouterView />`가 화면을 표시할 자리를 만듭니다.
6. `router/index.js`가 `/about` 경로를 확인합니다.
7. `/about`에 연결된 `AboutView.vue`를 불러옵니다.
8. `AboutView.vue`의 템플릿이 브라우저 화면에 표시됩니다.

## SPA와 Vue의 역할

Vue 애플리케이션은 보통 하나의 `index.html`을 기본 틀로 사용합니다.

```text
index.html
└── <div id="app">
       └── App.vue
              └── RouterView
                     └── 현재 경로에 맞는 View
```

페이지를 이동할 때마다 HTML 전체를 다시 불러오는 대신, Router가 필요한 화면만 교체합니다. 따라서 전체 페이지 새로고침을 줄이고, 화면 전환을 빠르고 자연스럽게 만들 수 있습니다.

## 각 폴더의 역할 정리

```text
components = 화면을 구성하는 작은 부품
views      = 부품을 조립한 완성 페이지
router     = 페이지 이동 규칙
stores     = 여러 화면이 함께 사용하는 데이터
assets     = Vite가 처리할 이미지, CSS, 폰트
public     = 그대로 제공할 정적 파일
```
