# JavaScript 데이터 타입과 Vue 반응형 데이터 구조

## 1. 데이터 타입의 큰 분류

```text
데이터
│
├── 원시값(Primitive Type)
│
└── 참조값(Reference Type)
```

## 2. 원시값(Primitive Value)

### 정의

원시값은 하나의 값 자체를 저장하는 가장 기본적인 데이터 형태다.

```text
string
number
boolean
null
undefined
symbol
bigint
```

### 예시

```javascript
const age = 20
const name = 'Kim'
const isLogin = true
```

### 메모리 구조

```text
age
 |
 ↓
20
```

원시값은 값 자체를 저장한다.

### 값 복사

원시값을 복사하면 메모리 주소가 아니라 값 자체가 복사된다.

```javascript
let a = 10
let b = a

b = 20

console.log(a)
// 10
```

```text
a
↓
10

b
↓
10
```

처음에는 같은 값이지만, 값을 복사한 뒤에는 서로 독립적으로 동작한다.

## 3. 객체(Object)

### 정의

객체는 여러 개의 데이터를 하나로 묶어서 저장하는 자료 구조다.

### 예시

```javascript
const user = {
  name: 'Kim',
  age: 20,
  city: 'Seoul'
}
```

### 구조

```text
user
 |
 ↓
객체
 |
 ├── name: Kim
 ├── age: 20
 └── city: Seoul
```

객체는 속성(property)을 가진다.

### 속성 접근

```javascript
user.name
// 'Kim'
```

`user.name`은 `user` 객체 안에 있는 `name` 값을 가져온다.

## 4. 배열(Array)

### 정의

배열은 여러 개의 값을 순서대로 저장하는 객체다.

배열도 객체의 한 종류이지만, 일반적으로 순서가 있는 여러 데이터를 저장할 때 사용한다.

### 예시

```javascript
const fruits = [
  'apple',
  'banana',
  'orange'
]
```

### 구조

```text
fruits
 |
 ↓
Array
 |
 ├── 0: apple
 ├── 1: banana
 └── 2: orange
```

배열은 index(순서)로 접근한다.

```javascript
fruits[0]
// 'apple'
```

## 5. 객체와 배열의 차이

둘 다 여러 데이터를 저장하지만 목적이 다르다.

### 객체

객체는 하나의 대상을 표현할 때 사용한다.

```javascript
const user = {
  name: 'Kim',
  age: 20
}
```

위 객체는 사용자 1명의 정보를 표현한다.

### 배열

배열은 여러 데이터의 목록을 표현할 때 사용한다.

```javascript
const users = [
  {
    name: 'Kim'
  },
  {
    name: 'Lee'
  }
]
```

위 배열은 사용자 목록을 표현한다.

| 구분 | 객체 | 배열 |
| --- | --- | --- |
| 목적 | 하나의 대상 표현 | 여러 데이터 목록 |
| 접근 | 이름(key) | 순서(index) |
| 예시 | `user` | `users` |

## 6. 객체 안에 객체를 넣을 수 있다

객체 안에 다른 객체를 넣는 구조는 실무에서 자주 사용된다.

```javascript
const user = {
  name: 'Kim',
  address: {
    city: 'Seoul',
    zip: '12345'
  }
}
```

### 구조

```text
user
├── name
│
└── address
    |
    ├── city
    └── zip
```

### 접근

```javascript
user.address.city
// 'Seoul'
```

## 7. 배열 안에 객체를 넣을 수 있다

Vue에서 자주 볼 수 있는 형태다.

```javascript
const todos = [
  {
    id: 1,
    text: 'Vue 공부'
  },
  {
    id: 2,
    text: 'JavaScript 공부'
  }
]
```

### 구조

```text
todos 배열

0
 |
 └── 객체
      ├── id
      └── text

1
 |
 └── 객체
      ├── id
      └── text
```

### 접근

```javascript
todos[0].text
// 'Vue 공부'
```

## 8. Vue에서 객체와 배열이 중요한 이유

Vue에서는 객체를 `ref`로 감싸서 반응형 상태로 만들 수 있다.

```javascript
import { ref } from 'vue'

const user = ref({
  name: 'Kim',
  age: 20
})
```

### 데이터 구조

```text
ref
 |
 ↓
객체
 |
 ├── name
 └── age
```

`ref`로 만든 객체의 값에 접근할 때는 `.value`를 사용한다.

```javascript
user.value.age
```

### 데이터 접근 흐름

```text
user
 ↓
ref 객체
 ↓
value
 ↓
일반 객체
 ↓
age
```

## 9. 배열도 같은 원리로 접근한다

```javascript
import { ref } from 'vue'

const todos = ref([
  {
    id: 1,
    text: '공부'
  }
])
```

배열 안의 객체에 접근할 때는 `.value`와 index를 함께 사용한다.

```javascript
todos.value[0].text
// '공부'
```

### 데이터 접근 흐름

```text
todos
 ↓
ref 객체
 ↓
value
 ↓
배열
 ↓
0번째 객체
 ↓
text
```

## 10. 결론

개발할 때는 데이터가 다음과 같은 구조로 감싸져 있다고 생각하면 된다.

```javascript
import { ref } from 'vue'

const weatherList = ref([
  {
    id: 1,
    name: '서울',
    temp: 30
  }
])
```

```text
weatherList
 |
 ↓
ref
 |
 ↓
value
 |
 ↓
Array
 |
 ↓
Object
 |
 ├── id
 ├── name
 └── temp
```

따라서 다음과 같은 방식으로 데이터를 추출할 수 있다.

```javascript
weatherList.value[0].temp
// 30
```

## 11. Vue 공부에서 꼭 구분해야 하는 용어

| 용어 | 의미 |
| --- | --- |
| 값(value) | `20`, `'hello'`, `true` 같은 단일 데이터 |
| 변수(variable) | 값을 저장하는 이름 |
| 객체(object) | key를 사용해 데이터를 저장하는 자료 구조 |
| 속성(property) | 객체 내부에 저장된 데이터 |
| 배열(array) | 데이터를 순서대로 저장하는 자료 구조 |
| 원소(element) | 배열 안에 있는 하나의 데이터 |
| 참조(reference) | 객체의 주소를 가리키는 것 |

# 1. Vue.js 기본 용어 

## 1) component 

화면을 구성하는 독립적인 UI 부품 

WeatherParent.vue
├── SearchBar.vue
├── WeatherCard.vue
└── WeatherForecast.vue

Vue 컴포넌트는 일반적으로 세 부분으로 구성한다. 

<script setup>
// JavaScript 로직
</script>

<template>
  <!-- 화면 구조 -->
</template>

<style scoped>
/* CSS 디자인 */
</style>

## 2) Template

브라우저에 표시한 HTML 구조를 작성하는 영역 

<template>
  <h1>{{ title }}</h1>
</template>

{{ }} 는 JavaScript 값을 화면에 출력하는 문자열 보간법 

# 3) Directive 

HTML 태그에 Vue 기능을 추가하는 문법, 대부분 V- 시작함. 

<p v-if="isVisible">보이는 문장</p>
<button @click="increase">증가</button>
<input v-model="name" />

대표적인 Directive 

| 문법 | 역할 |
|---|---|
| `v-if` | 조건에 따라 요소 생성·제거 |
| `v-show` | 조건에 따라 CSS로 숨김 |
| `v-for` | 배열을 반복 출력 |
| `v-model` | 입력값과 상태를 양방향 연결 |
| `v-bind` 또는 `:` | 속성에 JavaScript 값 연결 |
| `v-on` 또는 `@` | 이벤트 연결 |

# 4) Reactive State 

값이 변경되었을 때, Vue가 이를 감지하고 화면을 자동으로 다시 갱신하는 상태 

<script setup>
import { ref } from 'vue'

const count = ref(0)
</script>

<template>
  <p>{{ count }}</p>
</template>

count가 변경되면 화면의 숫자도 자동으로 변경된다. 

# 5) ref

숫자, 문자열, 불리언, 객체, 배열 등을 반응형으로 만드는 함수. 

const count = ref(0)
const name = ref('민형')
const user = ref({
  age: 25,
})

JavaScript 영역에서는 .value가 필요하다. 

count.value++
user.value.age++

그러나 tempalte에서는 .value를 사용하지 않는다. 

<p>{{ count }}</p>
<p>{{ user.age }}</p>

# 6) reactive 

주로 객체를 반응형으로 만드는 함수 

import { reactive } from 'vue'

const user = reactive({
  name: '민형',
  age: 25,
})

user.age++

reactive에서는 .value를 사용하지 않습니다. 

ref와 reactive 비교

const count = ref(0)
count.value++

const user = reactive({ age: 25 })
user.age++
# 7. Computed 

기존 반응형 상태를 이용해 새로운 계산 결과를 만드는 값.

const price = ref(10000)
const quantity = ref(3)

const totalPrice = computed(() => {
  return price.value * quantity.value
})

<p>총 가격: {{ totalPrice }}원</p>

특징 : 
- 의존하는 값이 바뀌면 자동으로 다시 계산
- 계산결과를 캐싱
- 기본적으로 읽기 전용
- 화면에 보여줄 파생 값을 만들 때 사용

const filteredUsers = computed(() => {
  return users.value.filter((user) =>
    user.name.includes(searchQuery.value)
  )
})

# 8) Method / Function

- 버튼 클릭이나 특정 동작이 발생했을 떄 실행하는 함수 

const count = ref(0)

const increase = () => {
  count.value++
}

<button @click="increase">증가</button>

computed는 값을 계산하고, 함수는 행동을 실행한다고 생각하면 쉽다. 

# 화면 제어 용어 

## 9) v-if 

조건이 참일 때만 HTML 요소를 생성합니다. 
<p v-if="isLoggedIn">로그인되었습니다.</p>
<p v-else>로그인이 필요합니다.</p>

조건이 거짓이면 실제 DOM에서 요소가 제거됨 

##  10) v-show

요소는 그대로 두고 CSS의 display: none으로 숨긴다. 

<p v-show="isVisible">내용</p>

v-if와 v-show

| 구분 | `v-if` | `v-show` |
|---|---|---|
| 거짓일 때 | DOM에서 제거 | CSS로 숨김 |
| 전환 비용 | 큼 | 작음 |
| 자주 열고 닫기 | 부적합 | 적합 |
| 처음부터 조건이 중요 | 적합 | 부적합 |

모달이나 드롭다운처럼 자구 열고 닫는 요소는 v-show가 유리 

## 11) v-for 

배열 데이터를 반복해서 화면에 표시 

const cities = ref([
  { id: 1, name: '서울' },
  { id: 2, name: '부산' },
])

<div
  v-for="city in cities"
  :key="city.id"
>
  {{ city.name }}
</div>

## 12) Key 

Vue가 반복된 각 요소를 구분하도록 제공하는 고유 식별자

<div v-for="city in cities" :key="city.id"

일반적으로 DB ID처럼 변하지 않는 값을 사용 

:key="city.id"

## 13) v-model 

입력창의 값과 반응형 상태를 양방향으로 연결합니다. 

const searchQuery = ref('') 

<input v-model = "searchQuery" /> 
<p>{{ searchQuery}} </p> 

## 14) Event 

클릭, 입력, 제출처럼 사용자가 발생시키는 동작 

<button @click="handleClick">클릭</button>

<input @input="handleInput" />

<form @submit.prevent="handleSubmit">


대표 이벤트 :

| 이벤트 | 의미 |
|---|---|
| `click` | 클릭 |
| `input` | 입력값 변경 |
| `change` | 입력 확정 또는 선택 변경 |
| `submit` | 폼 제출 |
| `keydown` | 키보드 누름 |

## 15) Event Modifier 

이벤트 동작을 간단히 제어하는 수식어 

<a @click.prevent = "handelLink"> 링크 </a> 
<button @click.stop = "handleClick"> 버튼 </button> 

| 수식어 | 기능 |
|---|---|
| `.prevent` | 기본 동작 방지 |
| `.stop` | 이벤트 버블링 방지 |
| `.once` | 한 번만 실행 |
| `.self` | 자신을 직접 클릭한 경우만 실행 |

# 3. 컴포넌트 통신 용어 

## 16) Props

부모 컴포넌트가 자식 컴포넌트에 데이터를 전달하는 방법 

부모 

<WeatherCard 
    :city = "selectedCity"
    title = "현재 날씨"
/> 

자식 

<script setup>
const props = defineProps({
  city: {
    type: Object,
    required: true,
  },
  title: {
    type: String,
    default: '',
  },
})
</script>

<template>
  <h2>{{ title }}</h2>
  <p>{{ city.name }}</p>
</template>

데이터 흐름: 

부모  -> props -> 자식 

Props는 자식에서 직접 수정하지 않는 것이 원칙 

## 17) Emit 

자식 컴포넌트가 부모 컴포넌트에 이벤트나 데이터를 전달하는 방법 

자식 

<script setup>
const emit = defineEmits(['select-city'])

const handleClick = () => {
  emit('select-city', '서울')
}
</script>

<template>
  <button @click="handleClick">서울 선택</button>
</template>

부모 

<WeatherCard @select-city="handleSelectCity" />
const handleSelectCity = (cityName) => {
    console.log(cityName)
}

데이터 흐름: 

자식 -> emit -> 부모 

정리하면: 

부모가 자식에게 데이터 전달: Props
자식이 부모에게 알림 전달: Emit

## 18) Slot 

부모가 자식 컴포넌트의 특정 위치에 HTML 내용을 삽입하는 기능 

자식 

<template>
  <div class="card">
    <slot />
  </div>
</template>

부모 

<BaseCard>
    <h2> 서울 날씨 </h2>
    <p> 현재 기온 28도 </p>
</BaseCard> 

BaseCard는 공통 틀을 만들고, 내부 콘텐츠는 부모가 결정 

# 4.상태 변화 감시 

## 19) watch 

특정 상태의 변경을 감지한 후 부수 효과를 실행한 이유 

watch(searchQuery, (newValue, oldValue) => {
  console.log('새 값:', newValue)
  console.log('이전 값:', oldValue)
})

다음과 같은 작업에 적합

- API 요청 
- localStroage 저장 
- 로그 기록 
- 특정 값 변경 시 별도 처리 

객체의 특정 속성을 감시할 수 있다. 

watch(
    () => user.value.age, 
    (newAge, oldAge) => {
        console.log(newAge,oldAge)
    }
)
