# 오답 개념 

FROM TEAM T INNER JOIN STADIUM S
USING (T.STADIUM_ID = S.STADIUM_ID);

-> 이게 아니라 

FROM TEAM T INNER JOIN STADIUM S
USING (STADIUM_ID);

USING(A.id = B.id) ❌ -> 이거 낚시용 문제 

(+)는 B(게시글) 쪽이 없어도 A(게시판)를 남기는 LEFT OUTER JOIN 뜻

| 명령어 | 의미 | 이 문제 결과 |
|---|---|---|
| `UNION ALL` | 두 조회 결과를 그대로 세로로 합침. 중복도 유지 | ①: `COL1별 합계` + `전체 합계` |
| `GROUPING SETS` | 원하는 그룹 기준만 골라 집계 | ②: `COL1별 합계`만 |
| `ROLLUP` | 소계와 전체 합계를 단계적으로 만듦 | ③: 컬럼 하나라 `COL1별 합계` + `전체 합계` |
| `CUBE` | 가능한 그룹 조합의 집계를 모두 만듦 | ④: 컬럼 하나라 `COL1별 합계` + `전체 합계` |

GRANT SELECT ON EMP TO USER2 WITH GRANT OPTION;
처럼 다시 권한 부여 능력까지 줄 수도 있습니다.
즉, 권한을 받는 사람이 다시 권한을 줄 수 있게 할지는 선택할 수 있습니다

GRANT SELECT ON EMP TO PUBLIC;
PUBLIC은 특정 사용자가 아니라 모든 사용자를 의미합니다.
따라서 모든 사용자에게 해당 권한을 허용합니다.

권한이 연쇄적으로 취소되지 않는다고 했지만, 실제로는 연쇄적으로 취소될 수 있습니다.

예를 들어:
A → B → C
- A가 B에게 WITH GRANT OPTION으로 권한 부여
- B가 C에게 권한 부여
- A가 B의 권한 취소
그러면 B가 C에게 줬던 권한도 함께 취소됩니다.

한을 부여한 사용자는 자신이 부여한 권한을 취소할 수 있습니다.
REVOKE SELECT ON EMP FROM USER2;
