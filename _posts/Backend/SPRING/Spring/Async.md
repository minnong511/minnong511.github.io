# Async : Asynchronous 

> 어떤 작업이 끝날 때까지 기다리지 않고, 다음 작업을 먼저 진행하는 방식 

예를 들어 동기 방식

A 작업 시작
↓
A 작업 끝날 때까지 기다림
↓
B 작업 시작
↓
B 작업 완료

반면 비동기는 

A 작업 시작
↓
A 작업 기다리는 동안 B 작업 진행
↓
A 완료되면 결과 처리

예를 들어 서버에서 이메일을 보내는 작업이 5초 걸린다치면 

회원 저장 0.1초
↓
이메일 전송 5초
↓
응답

총 약 5.1초

비동기로 처리

회원 저장
↓
이메일 전송 요청만 맡김 ──────→ 다른 Thread에서 이메일 전송
↓
사용자에게 바로 응답

Spring에서는 대표적으로 @Async를 사용 

@Async
public void sendEmail() {
    // 시간이 오래 걸리는 이메일 전송
}

### Async를 쓰는 이유 

특히 이런 작업에 좋다

이메일 전송
파일 업로드
외부 API 호출
알림 발송
이미지 처리
로그 처리

핵심은 CPU 계산을 무조건 빠르게 만든다는 개념이 아니라, 기다리는 시간을 효율적으로 활용하는 것

Sync
→ 작업 완료까지 기다림

Async
→ 작업을 맡기고 기다리지 않음

Thread
→ 실제 작업을 수행하는 실행 흐름

Async는 오래 걸리는 작업의 완료를 기다리지 않고 다른 작업을 계속 수행할 수 있도록 하는 비동기 실행 방식

Spring에서 @Async, Python의 async/await, JavaScript의 Promise가 전부 이 비동기 개념과 연결
