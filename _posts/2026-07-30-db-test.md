## 학습 목표

PostgreSQL에 연결한 뒤 현재 데이터베이스와 스키마를 확인하고, 기본 SQL이 실행되는 흐름을 기록한다.

## 확인한 내용

### 연결 정보 확인

연결이 성공했는지 확인할 때는 현재 데이터베이스와 스키마를 먼저 조회한다.

```sql
SELECT current_database(), current_schema();
```

### 기본 조회 실행

조회 대상과 조건을 분리해 작성하면 쿼리의 의도와 결과를 확인하기 쉽다.

```sql
SELECT id, name
FROM sample_table
WHERE active = true
ORDER BY id;
```

- 실제 사용한 테이블 구조와 실행 결과를 추가한다.
- `EXPLAIN ANALYZE`로 실행 계획과 인덱스 사용 여부를 확인한다.
- 트랜잭션과 예외 상황에서의 동작을 정리한다.
